# 术语表（Glossary）

本文档统一系统中使用的核心术语，避免同名异义或异名同义。

## 智能体（Agent）
| 术语 | 英文/标识 | 说明 |
|------|-----------|------|
| 技术分析师 | TechnicalAnalyst / `technical_analyst.py` | 阶段一硬编码，计算技术指标并生成技术分析报告 |
| 基本面分析师 | FundamentalAnalyst / `fundamental_analyst.py` | 阶段一硬编码，计算财务维度评分并生成基本面分析报告 |
| 舆情分析师 | SentimentAnalyst / `sentiment_analyst.py` | 阶段一硬编码，NLP 分析与情绪量化并生成舆情分析报告 |
| 多头研究员 | BullResearcher / `bull_researcher.py` | 阶段二 ReAct，提取看涨论据，输出多头观点报告 |
| 空头研究员 | BearResearcher / `bear_researcher.py` | 阶段二 ReAct，提取看跌论据，输出空头观点报告（旧称「分头研究员」，已废弃） |
| 研究经理 | ResearchManager / `research_manager.py` | 阶段二 ReAct，裁决多空分歧，输出综合分析报告 |
| 策略执行agent | StrategyExecutor / `strategy_executor.py` | 阶段三硬编码，策略匹配→评分→推荐（旧称「策略执行器/引擎」，已废弃） |
| 代码生成器 | CodeGenerator / `code_generator.py` | 自定义算法管线 ReAct，LLM 生成 Python 算法代码 |

## 阶段（Phase）
| 术语 | 说明 |
|------|------|
| 阶段一 | 数据获取与基础分析（技术/基本面/舆情分析师 → 汇总节点） |
| 阶段二 | 信息综合与辩论（多头/空头研究员 → 研究经理） |
| 阶段三 | 策略执行与推荐生成（默认硬编码管线 / 自定义算法管线） |

## 节点（Node）
| 术语 | 说明 |
|------|------|
| 汇总节点 | 阶段一末尾汇聚三份报告与三维度得分的节点，输出 `StageOneMergeState`（旧称「汇聚节点」，已废弃） |
| 策略匹配引擎 | 阶段三默认管线中识别策略类型与权重的节点 |
| 评分计算器 | 阶段三默认管线中加权计算得分的节点 |
| 推荐决策器 | 阶段三默认管线中阈值比较与推荐生成的节点 |

## 报告（Report）
| 术语 | 说明 |
|------|------|
| 技术分析报告 | 技术分析师输出，含趋势/关键价位/技术评分 |
| 基本面分析报告 | 基本面分析师输出，含估值/财务评分/优势风险 |
| 舆情分析报告 | 舆情分析师输出，含情绪/热度/关键事件 |
| 多头观点报告 | 多头研究员输出，`BullishReport` |
| 空头观点报告 | 空头研究员输出，`BearishReport` |
| 综合分析报告 | 研究经理输出，`ComprehensiveReport` |
| 最终推荐报告 | 策略执行 agent 输出，含 action/score/reasoning |

## 状态（State）
| 术语 | 说明 |
|------|------|
| GlobalState | 全局工作流状态 |
| StageOneMergeState | 阶段一汇总节点的状态 |
| TechnicalAgentState / FundamentalAgentState / SentimentAgentState | 阶段一三个分析师的状态 |
| BullishAgentState / BearishAgentState | 多头/空头研究员状态 |
| ResearchManagerState | 研究经理状态 |
| StrategyAgentState | 策略执行 agent 状态 |
| CodeGenSandboxState | 代码生成与沙箱执行引擎状态 |

## 其他
| 术语 | 说明 |
|------|------|
| ReAct | 「思考-行动-观察」循环推理范式 |
| workflow_id | 工作流唯一标识，贯穿全流程 |
| ts_code | Tushare 标准股票代码（如 000001.SZ） |
| 自定义算法 | 用户在线定义并执行的推荐算法（代码级自定义） |
