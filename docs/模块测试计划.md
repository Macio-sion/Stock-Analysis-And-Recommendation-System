# 模块测试计划

本文档是「开发阶段任务清单」的配套测试计划，汇总各阶段模块的**可测接口、输入样例、期望输出与验证点**，用于逐模块数据测试。

## 测试总则

1. **独立可测**：每个模块脱离完整工作流，输入样例数据即可调用并验证输出。
2. **数据来源**：优先使用真实数据（Tushare 行情/财务、alphaAI 舆情），辅以构造样例覆盖边界/异常。
3. **验证标准**：输出字段名与类型须与设计文档（概要/详细设计）定义的 State/Report 结构一致。
4. **落库/回放**：涉及持久化的模块，验证写入后可读回且字段一致。
5. **配套测试**：每个模块对应 `tests/` 下的一个测试函数，附一组真实样例。

## 测试数据样例约定

- 标准标的：`000001.SZ`（平安银行）、`600000.SH`（浦发银行）。
- 时间窗口：`start_date=20250101`、`end_date=20260831`。
- 策略样例：价值型（0.7/0.2/0.1）、成长型（0.5/0.3/0.2）、技术型（0.6/0.2/0.2）。
- 算法描述样例：见阶段 10 的输入样例。
