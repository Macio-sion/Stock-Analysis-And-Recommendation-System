# 日志与系统配置
## 日志配置

使用loguru库配置日志记录。
```python
import loguru
logger = loguru.logger
```
日志记录级别：
- DEBUG：调试信息
- INFO：一般信息
- WARNING：警告信息
- ERROR：错误信息
- CRITICAL：严重错误信息

### 实时日志推送（WebSocket）
自定义算法执行过程中，编译与执行日志除写入文件外，还通过 WebSocket 实时推送至前端。
- 推送通道：WebSocket（`src/streaming/websocket.py`）
- 事件类型：code / log / metric / status
- 日志格式：{"type": "log", "execution_id": "...", "seq": N, "level": "info", "message": "...", "timestamp": "..."}

## 系统配置

### 数据库参数

URI：数据库连接字符串
PostgreSQL数据库连接字符串示例：
```
postgresql://postgres:root@127.0.0.1:5432/{database_name}
```

### tushare参数
tushare_token：tushare API密钥（通过环境变量 TUSHARE_TOKEN 注入，勿明文写入配置）

### 沙箱执行环境配置（Docker）
自定义算法在 Docker 容器沙箱中隔离执行，相关配置如下：
- 隔离方式：每次执行创建独立容器，结束后销毁
- 镜像：python:3.11-slim（预装 numpy、pandas 等白名单依赖）
- CPU 限制：1 核
- 内存限制：256 MB
- 执行超时：30 s
- 网络访问：禁用
- 文件系统：只读

### 代码生成引擎配置（LLM）
- 模型：与全局 LLM 配置共用（Ollama/OpenAI）
- 代码模板：`src/codegen/templates.py`（入口函数 recommend 模板）
- 白名单依赖：numpy、pandas、math、statistics
- 危险模块黑名单：os、sys、subprocess、socket、requests
