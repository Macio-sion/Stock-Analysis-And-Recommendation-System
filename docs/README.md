## 阅读顺序建议

1. **需求文档.md** — 先了解系统目标、整体架构与三阶段工作流。
2. **业务概念文档集/** — 建立工作节点与数据的整体认知。
3. **架构决策记录.md** — 理解关键技术选型理由。
4. **业务智能体工作流文档集/** — 深入各 agent 的概要/详细设计。
5. **股票提示词设计集/** — 了解 ReAct agent 的提示词设计。
6. 按需查阅横切文档：安全、接口、错误处理、持久化、部署、测试。

## 文档间关系

- 需求文档定义「做什么」，概要/详细设计定义「怎么做」，提示词是「智能体如何思考」。
- [需求追溯矩阵](需求追溯矩阵.md) 建立需求到设计的映射。
- [术语表](术语表.md) 统一全库命名
- 各横切文档（安全/接口/错误/部署/测试）是跨阶段的通用约束，适用于所有 agent。

## 核心架构速览
三阶段工作流：`阶段一（硬编码：技术/基本面/舆情分析 → 汇总）→ 阶段二（ReAct：多空研究员 → 研究经理）→ 阶段三（硬编码推荐 / 自定义算法：LLM 生成 + Docker 沙箱执行）`，实时日志与曲线通过 WebSocket 推送。
