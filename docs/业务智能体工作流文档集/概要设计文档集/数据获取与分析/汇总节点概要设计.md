## 图状态维护
```python
class StageOneMergeState:
    """阶段一汇聚后的状态"""
    # 工作流标识
    workflow_id: str
    ts_code: str
    # 三个Agent的完整报告
    technical_report: Dict[str, Any]      # 来自TechnicalAgentState.technical_report
    fundamental_report: Dict[str, Any]    # 来自FundamentalAgentState.fundamental_report
    sentiment_report: Dict[str, Any]      # 来自SentimentAgentState.sentiment_report
    # 三个Agent的评分
    technical_score: float
    fundamental_score: float
    sentiment_score: float
    # 汇总信息
    all_scores: Dict[str, float] = field(default_factory=dict)
    # {"technical": 72, "fundamental": 68, "sentiment": 65}
    # 执行汇总
    total_duration_ms: Optional[int] = None
    stage_status: str = "completed"       # completed / partial_failed / failed
    errors: List[str] = field(default_factory=list)
```
